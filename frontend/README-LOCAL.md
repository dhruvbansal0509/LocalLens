# LocalLens Frontend (local Windows setup)

This folder contains the Lovable-generated LocalLens frontend, organised for local development beside the Flask API. The visual design has been preserved.

## 1. Configure MapTiler

Copy `.env.local.example` to `.env.local`, then set your real MapTiler browser key:

```env
VITE_MAPTILER_KEY=your_actual_key
VITE_API_BASE_URL=http://127.0.0.1:5000
```

Do not paste the key into chat or commit `.env.local`. Restrict the browser key in MapTiler Cloud to `http://127.0.0.1:8085` and `http://localhost:8085` as appropriate. The key is browser-visible and is not a private backend secret.

## 2. Install frontend dependencies

Open a terminal in this `frontend` folder and run:

```powershell
npm install
```

## 3. Start the frontend

Start the Flask API from the parent LocalLens Python project first. Then, in this folder, run:

```powershell
npm run dev
```

The frontend is configured for `http://127.0.0.1:8085`, matching the CORS origin currently allowed by the LocalLens Flask API.

## Notes

- The frontend uses TanStack Start and its configured Vite plugin; the route tree is generated by the project tooling.
- The local SQLite database is managed by the Flask backend and must stay outside this frontend folder.
- The application is intended to run locally. No GitHub connection, Cloudflare tunnel, or public deployment is included.
- If `npm install` reports an error, save the full terminal output before changing package versions.
